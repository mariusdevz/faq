# FAQ Page

A responsive FAQ page built as part of a DevChallenges frontend challenge.

## Overview

This project is a simple FAQ page designed to present frequently asked questions and answers in a clean, readable layout.

## Features

- Semantic HTML structure
- Responsive layout
- Organized FAQ sections
- Custom CSS styling
- Mobile-friendly design

## Built With

- HTML5
- CSS3
- CSS Media Queries

## What I Learned

- Structuring pages with semantic HTML.
- Creating responsive layouts using CSS.
- Using media queries to adapt layouts to different screen sizes.
- Improving content readability and page organization.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/mariusdevz/faq.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
